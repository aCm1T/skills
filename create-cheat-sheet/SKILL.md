# 制作考试 CP

把用户指定的学习材料整理成便于现场查找的纸质速查表。以本次材料和要求为准；旧 CP 可以复用版式，不能代替重新核对内容和范围。

## 输入与可调整的默认值

- 优先读取当前附件、指定文件夹和已有 CP。材料通常包括 lecture 原版与批注版、tutorial、homework、样卷、已有解答及考试通知；只使用实际可访问且属于本次范围的文件。
- 从当前请求和相关会话提取考试范围、页数或纸张限制、语言、排序、字号偏好、允许携带的材料形式、输出位置及修改边界。已经明确的信息不重复询问。
- 没有另行指定时，采用英文正文、A4 纵向两页（双面一张）、按实际授课顺序排列，交付 PDF 与 LaTeX 源文件；三栏是紧凑版式的起点。中文沟通不自动意味着正文必须中文。这些是制作默认值，不是对课程考试规则的断言。
- 缺少课程材料或考试范围存在会明显改变内容的歧义时，提出具体问题；等待期间可盘点文件、提取内容和准备版式。没有官方范围时，把用户指定范围或暂定复习范围明确记下，不能把“最新上传 lecture”或样卷内容升级成官方截止范围。
- 默认在本次工作区的 `output/pdf/` 保存最终文件，在 `tmp/pdfs/` 放提取文本、构建日志及预览；遵从用户或仓库已有约定。运行产物不写进已安装的 skill 目录。

## 从材料到内容

1. **建立来源对应。** 逐份核对 lecture 编号、标题、页码、批注和版本，合并同一份课件的重复副本，保留批注带来的补充。PDF 提取文字后查看含公式、图片或图表的相关页面，不能把提取失败误判为内容不存在。原版与批注、课件与解答冲突时记录差异并核对，不能静默混用。
2. **确定覆盖与顺序。** 用实际课件建立内部对应表：主题、来源文件及 PDF 页码、关键公式或算法、练习对应、拟放位置。按授课出现顺序排列；跨 lecture 的主题可在首次系统讲授处集中，并留清晰交叉提示。tutorial、作业和样卷用于发现应用步骤、易错点和遗漏，不把整套答案复制进 CP。附加内容标明 supplement，放在相关主题之后或末尾。
3. **压缩成可用条目。** 每个主题保留“何时用 → 条件与符号 → 核心公式或算法 → 必要推导或操作步骤”。只保留能帮助选方法、代入或避免错误的短解释。推导不能省掉决定变换方向、符号或条件的那一步；例如先写输入关系再写变换结果。区别一般结论、渐近近似和题目特例，保持课件参数化及符号约定一致。
4. **按题型反查。** 对照 tutorial、homework 和样卷，确认 CP 足以定位所需方法、识别条件并执行关键计算。检查公式的定义域、分布参数、上下标、独立性条件、矩阵维度、分位点方向及单位。不承诺考试全覆盖，也不以样卷频率替代用户指定范围。

覆盖对应表是工作证据，不必占用打印页数。正文可用简短 `L3 / inverse transform` 等标题帮助定位；不要加入个人身份、制作日志、安装命令或未经要求的长页脚。

## 排版、修订与验证

制作 PDF 前读 [PDF 制作与核验](references/pdf-production.md)，其中包含依赖准备、编译、视觉检查与局部修改的验证方法。新建英文 LaTeX 文件可从 [两页 A4 版式模板](assets/cheat-sheet.tex) 复制到工作区开始；模板中的示例是排版演示，全部替换后才能作为课程 CP 交付。已有源文件或指定格式优先，不强制改用模板。

- 先去重复解释、调整条目组织和栏间分配，再压缩行距与字号。页数是硬限制时必须实际核对；不能靠裁掉内容或缩成不可读文字宣称完成。
- “按 lecture 重排”默认保留已有正文、公式和条件，建立旧条目到新位置的对应；确需内容修正时明确说明。“只删页脚”“其他不变”限定修改范围，核对正文及未授权区域。
- 最终版本须同时通过内容对照、页数与纸张检查、公式和字体检查，以及每页渲染后的视觉检查。重新编译或修改后的文件重新检查；旧预览不能证明新文件合格。
- 源文件应能重建最终 PDF。若精确 PDF 局部编辑后无法同步源文件，保留原件并说明不一致；不得把过期源码称为最终可编辑版本。依赖或渲染受阻时交付可用部分，指出缺失的工具和未完成的验证。

## 交付

给出实际最终 PDF 和可编辑源文件的链接，简述覆盖范围、语言、页数、排序及关键检查。存在暂定范围、无法读取的材料、内容冲突、排版或重建缺口时准确说明。采用默认纸张时，可建议 A4、100% 实际尺寸、长边翻转双面打印；若考试另有规定则遵从规定。

用户只要最终文件时不额外打包缓存。需要打包时检查包内内容和完整性；原课件、私人批注和身份资料不随可分享的 skill 或模板发布。制作 CP 本身不授权上传课程平台或公开课程材料；当前会话已明确授权的外部操作不重复确认。
