# PDF 制作与核验

本指南适用于新建、重排和局部修订。先遵从用户已有模板与工具；以下命令是 LaTeX/Poppler 的一种可行路径。调用环境提供 PDF 专用 skill 时，也遵从其适用的工具要求。

## 环境与首次准备

- 使用已有 TeX 环境，或从 [Tectonic 官方项目](https://tectonic-typesetting.github.io/) 准备编译器；也可用 TeX Live 的 LuaLaTeX、XeLaTeX 或 pdfLaTeX。英文模板使用标准 LaTeX 包：`geometry`、`lmodern`、`amsmath`、`amssymb`、`multicol`、`xcolor`、`fancyhdr`。不包含机器专用字体路径。中文正文需要支持中文的引擎、文档类和已安装字体，例如 XeLaTeX/LuaLaTeX 配合 `ctex`；先做字体小样再排完整文件。
- 使用 [Poppler](https://poppler.freedesktop.org/) 的 `pdfinfo`、`pdffonts`、`pdftotext` 和 `pdftoppm` 查看结构、字体、提取文字并渲染。通过运行环境、系统包管理器或隔离环境准备缺失依赖；不覆盖现有工具或重复安装。
- Tectonic 第一次编译可能下载包和字体；保留编译器管理的缓存供后续复用。联网受限时先查现有缓存和字体，或改用可用的本地 TeX 环境。不要把下载或缺字体失败当作内容验证通过，也不要在公共模板中写死作者缓存路径。
- 模板编译路径已用 Tectonic 0.15.0 验证，结构与渲染命令已用 Poppler 26.05.0 验证；这些是已核对版本，不是最低版本约束。首次执行记录本机实际版本；升级引擎、宏包或字体后重查分页、缺字和公式外观。

## 工作文件与编译

复制模板到本次输出目录再编辑，保留原文件作为修订基线。模板含六个演示主题以及显式分页、分栏；按实际内容修改分栏位置，不能假定替换后仍然两页。通常无需图像或其他外部资源；确需资源时与源码一起交付并使用相对路径。

以下变量由本次任务设置，使用绝对工作路径。示例假定源码已经写好；编译输出先留在构建目录，核验后再交付对应 PDF。

```sh
SOURCE_TEX=/absolute/output/path/cheat-sheet.tex
BUILD_DIR=/absolute/work/path/tmp/pdfs/build
PDF_PATH="$BUILD_DIR/cheat-sheet.pdf"
PREVIEW_DIR=/absolute/work/path/tmp/pdfs/preview
mkdir -p "$BUILD_DIR" "$PREVIEW_DIR"
tectonic --keep-logs --outdir "$BUILD_DIR" "$SOURCE_TEX"
pdfinfo "$PDF_PATH"
pdffonts "$PDF_PATH"
pdftotext -layout "$PDF_PATH" "$BUILD_DIR/cheat-sheet.txt"
pdftotext -bbox "$PDF_PATH" "$BUILD_DIR/cheat-sheet-bbox.html"
pdftoppm -r 150 -png "$PDF_PATH" "$PREVIEW_DIR/page"
```

编译日志中的 `Overfull`、缺字、字体替换和未定义引用需要逐项判断、修复。行框告警与页面边界检查互补：在纸张内的文字仍可能越过栏边界。不要全局缩放公式来掩盖过宽内容；优先用 `aligned` 等换行，保留语义和推导顺序。若换引擎后中间产物不兼容，使用新的构建目录，保留用户源文件和旧成品。

## 成品核验

1. **材料与数学。** 对照内部覆盖对应表检查主题与来源，区分 PDF 文件页码和课件印刷页码。查看原页面以核对图像中的公式。按练习或样卷验证关键方法是否能实际使用；抽查分支、极端情况和容易混淆的条件。补充推导应能独立验证，不能借“课件如此”掩盖矛盾。
2. **结构与文字。** 读取实际 PDF 页数和每页尺寸。A4 纵向约为 595.28 × 841.89 pt；两页是默认目标而不是编译成功的推论。检查空白页、字体嵌入或缺失、替换字符、被截断公式与标题顺序。文本框边界可辅助发现页面越界，文字提取本身不能证明数学或排版正确。
3. **逐页视觉检查。** 打开最新渲染的全部页面，同时检查整页和局部放大图：栏的阅读方向、页内顺序、公式上下标、矩阵与分式、行距、栏间碰撞、页脚、图表标签及页面底部。估计 100% 实际打印时的可读性；放大预览能看清不等于打印后能读。
4. **源文件一致性。** 从最终源码重建，确认重建出的页数、文本和版式与交付 PDF 一致；无需要求 PDF 二进制完全相同，因为元数据可能变化。确认没有依赖未交付的资源或本机字体绝对路径。

页数超限时先删重复表述、合并相同定义、缩短非必要例子、调整分栏，再小幅调整字号与间距。用户同时要求内容全保留和固定页数，而可读性无法满足时，说明具体冲突并征求取舍，不静默丢内容或附加未授权页面。

## 重排与局部修改

- **重排：** 保存修改前版本及每条内容的对应位置，核对公式、适用条件与正文未丢失。忽略标题、顺序与排版标记后进行内容比较，再人工核对公式；简单词频相等不能证明公式相同。若发现旧公式有误，单独标明修正。
- **局部改字或页脚：** 优先同步修改源文件并重建。核对全文差异、页数与边界，对修改前后同一分辨率的页面做图像比较；差异应限制在授权区域，字体重排等额外变化需要处理。
- **只有 PDF 或重编译受阻：** 保留原件，选用能保持其余排版的 PDF 编辑方式。源文件缺失或失配要明确披露。覆盖文字的视觉遮挡不等于真正删除；删除要求需确认旧文字不再能从文本或内容对象中提取。完成后重新提取文本并渲染比较。

最终简述实际做过的检查和仍影响使用的限制。未渲染、材料未读全或无法从源文件重建时，分别报告；这些状态不能合并成“全部验证通过”。
